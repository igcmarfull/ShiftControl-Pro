# ShiftControl Pro V21

## Dashboard móvil compacto
- Se aplicó la propuesta móvil Opción 1.
- Personal, Ausencias y Cobertura aparecen en una fila compacta de tres tarjetas.
- Reemplazos, Turnos extra y Alertas aparecen como filas horizontales compactas.
- Se redujeron padding, alturas y tipografía únicamente en pantallas de hasta 620 px.
- La vista de escritorio conserva su distribución anterior.
- No se cambió la estructura de datos ni la lógica del sistema.
