# ShiftControl Pro V35 — Reportes de impresión profesional

- Se agregó una hoja A4 exclusiva para imprimir el reporte operativo.
- El reporte operativo impreso mantiene la lectura de carga por turnos A, B y C, junto con descansos, presentes, ausentes y total de turnos.
- Se agregó una hoja A4 exclusiva para el reporte contable.
- El reporte contable impreso contiene únicamente: días trabajados, ausencias, domingos, feriados, licencias, vacaciones y horas de atraso.
- La impresión oculta completamente barra lateral, navegación, botones, tarjetas y demás elementos de la aplicación.
- Se agregaron cabecera institucional, período, estación, fecha de emisión, usuario generador, resumen, observaciones, firma y pie de página.
- El tipo de reporte impreso depende de la pestaña activa al presionar “Imprimir reporte”.
