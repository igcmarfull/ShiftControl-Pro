# V37 · Directorio móvil de trabajadores

- Se reemplazó la tabla extensa de trabajadores en móvil por tarjetas compactas.
- Cada tarjeta muestra iniciales, nombre, cargo, estado, turno habitual y fecha de ingreso.
- Tocar una tarjeta abre la ficha completa del trabajador.
- Se añadieron acciones móviles para agregar personal, alternar dotación/todos y filtrar inactivos.
- Se incorporó un botón flotante para agregar trabajadores.
- La eliminación queda disponible desde la ficha y se mantiene en la tabla de escritorio.
- La vista de escritorio conserva la tabla completa sin cambios funcionales.
