# ShiftControl Pro V50

- Se eliminó la barra inferior móvil de cinco accesos.
- Se mantiene únicamente el botón `Centro`, conservando el icono de cuadrícula de V49.
- El botón funciona como launcher flotante, elevado sobre el borde inferior y compatible con el área segura del iPhone.
- El Centro se reorganizó en Inicio, Operación, Personal y Administración.
- Se conservaron Avisos, Pendientes y navegación por roles.
- En escritorio se mantiene el acceso Command existente.
