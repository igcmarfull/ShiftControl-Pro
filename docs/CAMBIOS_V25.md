# ShiftControl Pro V25

## Vista semanal móvil mejorada

- Se aplicó la barra de navegación compacta elegida como Opción 3.
- La fecha queda entre los botones de semana anterior y siguiente.
- Se añadió una segunda barra con Hoy, número de semana y acceso a la semana actual.
- La sincronización utiliza el mismo selector de fecha y las mismas funciones existentes.
- En móvil, la columna de trabajadoras dejó de quedar anclada durante el desplazamiento horizontal.
- La columna de trabajadoras se redujo a sus iniciales.
- Al tocar las iniciales se muestra temporalmente el nombre completo y el área o turno habitual.
- La vista de escritorio no fue modificada.
